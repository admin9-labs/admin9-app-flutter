# Admin9 Phase 0C Gate 1 测量记录

> 注意：这些数值只描述低保真结构稿的构造与验收下限，不是 Design Token、实现常量或最终视觉规格。

## 1. 画布与导出

| 项目 | 记录 |
| --- | --- |
| 页面内部模型 | 390x844 logical pixels |
| 审阅板 | 页面板 1800x1120px；故事板 1800x980px |
| 页面板缩放 | 内部 390lp 画布以 78% 放入审阅板；内部坐标仍按 logical pixels 标注 |
| 输出 | SVG 静态源 + PNG 静态审阅资产 |
| 证据性质 | 低保真设计结构；非当前 App 截图、非模拟器/真机证据 |

## 2. 结构测量

| 元素 | 标准稿构造值 | 大字号构造方式 | Gate 1 判断 |
| --- | --- | --- | --- |
| 主按钮 visual bounds | 约 44lp 高 | 内容增长至约 54lp | 不与输入框等高；不是 Token |
| 主按钮 hit bounds | 不小于 48lp 高 | 随视觉容器增长 | 满足 Android 48dp / iOS 44pt 结构下限 |
| 密码图标 hit bounds | 48x48lp | 保持不小于 48x48lp | 满足双端结构下限 |
| 二级页返回 hit bounds | 不小于 48x48lp | 保持不小于 48x48lp | 认证为“返回我的”；设置主列表为“返回我的”；选择页为“返回设置”；设备手势仍为 Unknown |
| 文字次操作 hit bounds | 不小于 48lp 高 | 保持不小于 48lp 高 | 返回登录、注册账号、找回账号均有独立虚线命中区 |
| Switch hit bounds | 52x48lp 虚线区域；visual switch 约 48x30lp | 尾部命中区保持，列表行随内容增高 | 满足 Android 48dp / iOS 44pt 结构下限 |
| 表单字段 visual bounds | 约 54lp 高 | 内容增长至约 62lp，错误另占内容高度 | 只校准节奏，不冻结固定高度 |
| 普通列表行 | 50-62lp | 68lp 起并按内容增长 | 整行可操作；尾部不挤压标签 |
| 设置大字号布尔行 | 不适用 | 82-100lp 结构示意 | 标签换行，开关保持独立区域 |

数值来自 SVG 内部构造坐标，可机械复查。最终视觉稿必须重新记录实际 visual bounds、hit bounds、系统字号、逻辑窗口和对比度，不能直接复制本表为 Token。

## 4. 对比度与辅助功能

- 普通文字目标至少 4.5:1。
- 大字和关键非文字边界目标至少 3:1。
- 低保真使用的蓝、红、灰只帮助标注结构，尚未作为最终颜色逐项计算。
- 错误、选择、开关、未接入和危险状态均同时使用文字或形状，不只依赖颜色。
- 真机读屏、Switch Control、TalkBack、系统高对比度和减少动态效果结果仍为 Unknown。

## 5. 资产生成可追溯性

PNG 由同目录 `sources/` 下的 SVG 静态源通过 macOS `sips -s format png` 生成。SVG 是可审阅设计源，不是 HTML、Flutter 页面或可运行应用。最终 Gate 1 报告记录每个 PNG 的尺寸与 SHA-256。
