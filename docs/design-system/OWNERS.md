# Design System Owners

This file assigns review responsibility only for changes proposed to the
upstream Admin9 App Starter repository. Forks choose their own maintainers and
review process.

| Upstream responsibility | Required reviewer | Record location |
| --- | --- | --- |
| Core contract, API, tokens and platform mapping | 冯齐跃 (`qiyue2015`), Starter maintainer | Design System change review |
| Default App identity and Brand Theme | 冯齐跃 (`qiyue2015`) | App configuration and visual review |
| Accessibility hard gates | 冯齐跃 (`qiyue2015`), accessibility/test reviewer | tests and acceptance evidence |
| Upstream release and deprecation | 冯齐跃 (`qiyue2015`), Starter maintainer | SemVer release notes and changelog |

The canonical upstream repository is
`https://github.com/admin9-labs/admin9-app-flutter.git`. `CODEOWNERS` and this
record identify upstream reviewers; they do not assign roles or obligations to
forks.
