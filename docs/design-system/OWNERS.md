# Design System Owners

| Responsibility | Required approver | Record location |
| --- | --- | --- |
| Core contract, API, tokens and platform mapping | Admin9 Foundation maintainer | Design System change review |
| Brand Theme | derived-app brand owner plus Core maintainer | `admin9-foundation.yaml` and theme review |
| Business behavior/content | derived-app product/feature owner | feature change review |
| accessibility hard gates | accessibility/test reviewer | acceptance report |
| release compatibility/deprecation | Foundation release maintainer | changelog and compatibility row |

v1.0 records role ownership because the repository has no CODEOWNERS or canonical remote. Before the first runtime implementation release, the organization MUST bind these roles to named maintainers in repository governance. Until then, external clone upgrade approval remains Unknown; no individual name is invented in this document.
